## 0. 修复后结论

修复后 8/8 份 PDF 均再次完成真实解析，单份耗时 4.1～5.7 秒；全部 LessonDocument 覆盖源 PDF 的每一页，源文件复核接口均返回 200，浏览器控制台无 warning/error。

跨页表格、页面分组、公式状态、装饰图片和移动端表格问题已修复。复杂多栏 OCR 在 Provider 已把两列文字合并为单个字符串时无法可靠反推原顺序；当前实现会删除可证明的重复尾句，并对其余可疑块显示人工复核提示及精确原页链接，避免将不可信文本静默当作正确内容。

复验结论：**真实链路、页面结构与 Web 渲染通过；Provider 内部跨栏串读已安全降级，但仍属于需人工复核的上游识别限制。** 详细复验数据见第 9 节。

## 1. 修复前结论（基线）

8/8 份 PDF 均成功完成真实解析，没有接口失败、资源 404 或前端控制台错误；单份解析耗时约 5～23 秒，中位数约 18.5 秒。链路的“可用性”通过，但“文档还原质量”未达到可验收水平。

核心问题不是大面积文字缺失，而是结构和语义退化：跨页表格被压成少量超大 HTML 表格块，页边界、章节分组、段落换行和公式语义大量丢失；复杂多栏教案还出现跨栏串读。当前结果更接近“可搜索的连续文本表格”，尚不能稳定还原源教案的阅读结构。

建议结论：**真实链路功能通过，版面与结构验收不通过。** 在修复 P0/P1 问题前，不建议把当前结果作为 DOCX 导出或可编辑 Web 教案的可信输入。

3. 对照每个任务的 `mineru/*_content_list.json`、`lesson-document.json` 和提取图片资源。

不包含：DOCX 导出视觉验收、人工逐字 OCR 正确率统计、MinerU 不同模型版本对比。

## 4. 修复前问题清单

### P0-1 多栏内容发生串读，语义顺序被破坏

影响样例：`3 古诗三首(1).pdf`。

可复现证据：

- `lesson-document.json` 的 block 21 出现“仿佛看到了长安城内，柳 内容的能力。”，“内容的能力”实际属于右侧“设计意图”栏，被拼入左侧教师活动正文。
- block 28 将“中秋节来源”和“王建作者资料”两栏交替串接，例如“中秋节源自对天象的 王建……崇拜由上古时代秋……”，已无法按正常阅读顺序理解。
- block 58/59 出现“开拓了学生的视”与下一表格单元格中的“野”分裂，说明列间内容与表格边界处理不稳定。

判断：MinerU 对复杂教案表格的跨栏阅读顺序识别失败，Adapter 当前直接信任 Provider 顺序，无法纠正。该问题会造成内容含义错误，优先级最高。

建议：在 `backend/app/adapters/` 中基于 `page_idx`、`bbox`、表格列区域做同页列归属校验；对同一行的不同列分别聚合，禁止把右列尾句并入左列。加入不依赖当前文字的三列表格回归样例。

### P0-2 LessonDocument v1 丢失页面与分组语义，跨页表格被压成超大块

影响样例：全部 8 份，数学教案最明显。

可复现证据：

- “第一单元 第2课时：在直线上表示数.pdf”共 6 页，MinerU 原始结果有 6 个 `table` 项，但第 1 项携带合并后的完整 `table_body`，后 5 项为空；Adapter 跳过空项，最终只生成 1 个表格块。
- 本轮 45 个 MinerU `table` 项中有 24 个跨页延续空项；这些页在 LessonDocument 中没有任何边界标记。
- 真实 Web 页面显示“1 个内容块”，桌面端 article 高约 3183px；页面之间的标题、板书、作业、反思分组变成一个连续表格。
- `LessonDocument v1` 的 block 模型没有 `pageIndex`、`section`、`group` 或通用分页语义，前端无法恢复 Provider 已提供的页序信息。

判断：这是协议与 Adapter 的共同缺口，不是单纯 CSS 问题。虽然正文大多仍存在，但源文档的阅读分组和相对空间关系已经丢失。

建议：调整 LessonDocument 协议，增加通用的页面/分组语义（例如 `pageBreak` 或 block 的 `sourcePage` + `groupId`），并在 Adapter 中将跨页表格按来源页或逻辑区段拆分；同步后端模型、前端类型、渲染器和 `docs/LESSON_DOCUMENT_V1.md`。

### P1-1 公式识别与现有 SymPy 校验链路不匹配

影响样例：`第一课时 圆柱的表面积（1）.pdf`、`解比例.pdf`、`鸽巢问题2.pdf`。

可复现证据：

- 共识别出 31 个带 `data-latex` 的公式，现有校验接口判定 14 个不可解析，占 45.2%。
- 圆柱公式 `S_{侧} = ch = \pi dh`、`S_{侧} = 2\pi rh` 等 3/3 均因中文下标无法被当前 SymPy Lark 解析。
- 比例表达式使用冒号，如 `x :57=1 :10`，现有校验器不能解析；余数写法 `8 \div 3 = 2 \cdots 2` 同样不能解析。
- `解比例.pdf` 的板书和作业区中，`1/24:5/6=x:9`、`8/21=0.4/x` 等公式退化成普通表格文本，无法使用公式编辑器，也失去原页的上下分式版式。

判断：其中一部分是 OCR/LaTeX 规范化问题，另一部分是校验器覆盖不足。当前“公式可编辑 + SymPy 校验”的产品承诺对小学教材常见的比例、中文下标和带余除法并不成立。

建议：在 Adapter 中统一比例、单位、中文下标和余数表达的规范化策略；FormulaService 按公式类别解析，不能把所有教材公式都当作单一符号表达式。对不能做符号等价判断的展示型公式，应明确返回“结构可渲染但不支持符号校验”，不要与 OCR 错误混为一类。

### P1-2 装饰性校徽被当作独立正文图片，且重复出现

影响样例：`第一课时 圆柱的表面积（1）.pdf`、`第一课时 圆柱的认识（1）.pdf`。

可复现证据：

- “圆柱的表面积”输出的第 1 个 LessonDocument block 是南宁青秀区教育局圆形 Logo，源页中它只是标题旁的装饰图标。
- “圆柱的认识”输出两个独立 Logo 图片块，对应不同页面上的重复页眉装饰；它们被插到“单元设计表”和“课时设计表”之前。
- 真正有教学意义的圆柱展开图、圆柱结构图和物品示例也被识别为图片，因此不能简单删除全部小图。

判断：图片缺少“装饰/内容”语义，重复页眉资产污染正文阅读顺序。

建议：在 Adapter 内综合位置、尺寸、跨页重复哈希和邻近标题关系，把重复页眉/Logo 标记为 decorative 并过滤；保留表格内的教学图示。新增“重复 Logo + 不同教学图”的通用回归测试。

### P1-3 段落、列表和换行在跨页表格中退化为连续文本

影响样例：除 `3 古诗三首(1).pdf` 外的表格型教案普遍存在。

可复现证据：

- Web 中大量单元格出现“1.温故知新。师……2.阅读与理解……”连续粘连，源页的项目换行和教学步骤层级消失。
- `解比例.pdf` 板书区被压成带换行的普通单元格文本；作业中的多道题没有列表结构。
- `LessonDocument` 虽支持 `list`、`heading`、`formula`，但这些语义嵌在整页 `table.html` 内后无法成为独立 block。

判断：文字覆盖率看似较高，但可编辑性、可复用性和阅读质量显著下降。

建议：对 layout table 的单元格内容做二次语义切分；保留 `<p>`、`<ol>/<ul>`、公式节点和明确换行，避免仅拼接为单段纯文本。

### P2-1 窄屏三列表格虽不横向溢出，但可读性较差

影响样例：三列“教师活动 / 学生活动 / 设计意图”教案。

可复现证据：

- 390×844 视口下页面没有横向溢出，资源加载正常。
- 三列仍被强制压在约 279px 的表格宽度内，单列文字频繁每 4～7 个汉字换行，产生极长纵向页面；没有列堆叠、重点列切换或横向滚动的明确策略。

判断：技术上响应式，但移动端阅读效率低。优先级低于内容结构正确性。

建议：在移动端对三列教学设计提供列堆叠或按行卡片化语义渲染；若协议暂不能表达列角色，至少为多列表格设置合理最小宽度并提供可发现的横向滚动提示。

### P2-2 文档标题主要依赖文件名

影响样例：全部样例，文件名与正文标题不一致时风险更高。

可复现证据：Adapter 默认使用文件名 stem 作为 `document.title`，只有出现 level 1 heading 时才替换。多数表格型 PDF 没有独立 heading，Web 标题因此直接来自文件名，而不是 MinerU 的 table caption 或表内标题。

判断：当前样例文件名大多可用，所以未造成严重错误，但无法保证上传任意命名文件时标题正确。

建议：优先使用首个可靠的标题/表格 caption/首行居中标题；无法可靠判断时再回退文件名，并保留来源字段供人工确认。

## 6. 修复前建议与验收标准

1. **先修阅读顺序**：三列表格不得跨列串句；人工抽查复杂样例时语义顺序正确。
2. **再补协议分组**：每个源页或逻辑区段在 LessonDocument 中可追踪，跨页表格不能退化为单一不可分割块。
3. **补公式分层校验**：区分“KaTeX 可渲染”“SymPy 可解析”“与原图等价”三个状态；小学教材常见比例、单位、中文下标和余数写法有明确结果。
4. **过滤装饰图片**：重复页眉 Logo 不进入正文，教学图示必须保留。
5. **最后优化移动端表格**：三列内容在 390px 宽度下保持可连续阅读。

建议最小回归集：

- 多页三列表格，左右列均包含长段落。
- 跨 5 页以上的连续表格，含板书、作业、反思区。
- 同页既有重复 Logo 又有教学示意图。
- 含比例、中文下标、单位、余数、上下分式的数学教案。
- 与当前样例文字完全无关的通用合成 PDF，防止针对样例硬编码。
