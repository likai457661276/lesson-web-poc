新增或调整的通用验证不依赖样例文件名、章节、正文或固定页码：

- 英文标题、独立正文和数据表保持上游块边界；即使左侧对齐、紧邻表格或内部段落间距很大，也不猜测性合并。
- 相同几何在 0～1 与 0～1000 两种坐标单位下产生相同边界、标题对齐和多栏结果；多栏另覆盖不同页面尺寸。
- 空结果、非对象块、缺图（含表格内图片）、无结构表格、无效列表条目及无法完整转换的嵌套内容明确失败，不保存为成功文档。
- 未知纯文本转换为带 `reviewNote` 的 paragraph；序列化往返保留内容与提示，不泄漏 Provider 字段。
- 不规则长短栏、短栏及混合公式 span 保留原文并提示复核；普通词间距和缺少版面信息不会触发强制重排。
- 用独立构造的跨页表格验证 `lines_deleted` 标记、页面尺寸和几何唯一匹配；无标记、错误页码/位置、重复匹配或仍有行内容时，不猜测为空续片。整份文档只有提示时仍失败。
- 表格内无引号的图片路径也能归档重写；缺图不保留失效路径冒充成功。
- 复核提示处于 Web 可编辑正文之外，编辑不会删除提示，导出 HTML 同样保留提示。

### 验证边界与后续验收

- 已保存文档不会自动重算；运行更新后的后端并重新上传，才能获得新的边界和完整性检查。不为旧开发数据引入迁移或双读逻辑。
- 删除了按几何猜测的表格前置文字合并及其专用样式。原先被人为包进表格的标题、正文现在独立输出，不再承诺这些区域还原成原 PDF 表格边框。
- 跨页片段、未知文本和可检测的不规则多栏仍需人工复核；没有检测到的复杂版面仍依赖 Provider 顺序。
- 独立扫描件、旋转、裁切、低清晰度、多语言及跨块复杂多栏尚未专项验收。当前只支持 PDF，不支持直接上传手机照片。
- 尚无独立留出集和逐字/结构标注，不能把以上结果解释为任意 PDF 的泛化准确率。后续应按文档模板、页面尺寸、扫描质量和布局类型分层选取未用于开发的样本，分别记录文字错误率、内容遗漏、阅读顺序及表格结构错误；真实 Provider 端到端测试需要有效 API 凭据，密钥不得写入结果或仓库。
