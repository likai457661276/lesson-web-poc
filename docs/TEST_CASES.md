### 修复验证

- 表格标题：5 份受影响样例的标题恢复；《古诗三首》的三个课时标题均保留为 `<caption>`，Web 与 DOCX 可见。浏览器编辑标题后保存返回 200，刷新仍保留修改；验证后已恢复原始标题。
- 多栏阅读顺序：《古诗三首》第 10 页的节日与作者介绍恢复为两列，Web 和渲染后的 DOCX 已人工检查。算法只读取版面几何与完整文字，不匹配该样例的文件名、页码或正文；另以不同文字、不同页尺寸及普通词间距验证。
- 中文公式：《圆柱的表面积》三处中文下标生成可编辑 Word 公式，并检查实际渲染。不支持的公式返回 `422 / DOCX_FORMULA_UNSUPPORTED`；契约测试覆盖单篇及批量导出，真实批量接口也已验证相同错误，防止静默生成 LaTeX 文本或不完整 ZIP。
- 单元格阅读顺序：圆柱展开图位于引导文字之后、后续说明之前；通用测试同时检查文字、图片、公式和后续文字的 XML 顺序。
- 任务恢复：浏览器额外上传一份样例，解析期间刷新 `/jobs/{jobId}`，继续轮询并自动进入文档；重新打开已完成任务 URL 也能跳转。失败与不存在任务由前端测试覆盖。
- 自动化验证：后端 `./mvnw test` 共 81 项通过；前端 `pnpm test` 共 23 项通过，`pnpm lint`、`pnpm build` 通过。

### 验证边界

- 未清空已有数据库；修复前已保存文档不会自动重新解析，应重新上传以获得标题及阅读顺序修复。
- 本次验证覆盖上述样例和已知缺陷，不表示 OCR 逐字正确或所有跨页、跨栏版面都能恢复。缺少可靠版面信息时保留原文，不按语义猜测；检测到分栏但文字核对失败时提示人工复核。
- 独立扫描件、旋转及裁切场景尚未专项验收。当前只支持 PDF，不支持直接上传手机照片。
- 前端构建存在主包超过 500 kB 的体积警告；构建成功，未在本轮扩大范围进行拆包优化。
